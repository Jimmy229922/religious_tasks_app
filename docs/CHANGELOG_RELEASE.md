# ملاحظات الإصدار 3.8.6+37

## الأمان والخصوصية

- ربط النسخ السحابي بجلسة Google وSupabase مصادق عليها وملكية `auth.uid()`.
- إضافة ترحيل RLS محلي لعزل النسخ الاحتياطية ومنع الكتابات العامة.
- تقليل محتوى النسخ الاحتياطي ووضع حد للحجم والتحقق من الأنواع.
- إضافة حذف النسخة السحابية للمستخدم الحالي.
- منع الاتصالات غير المشفرة وإزالة مسار تنزيل أو تثبيت APK داخل التطبيق.
- جعل الاستعادة المحلية ذرية بحيث لا تكتب أي عنصر قبل اكتمال التحقق، وتقسيم SQL إلى احتواء أمني ثم ترحيل ملكية.
- اشتراط هوية Google مؤكدة للتحدي العالمي مع حفظ الزيادات المعلقة وإعادة إرسالها.

## التوافق والاعتمادية

- اعتماد AAB وGoogle Play كمسار الإصدار.
- استهداف Android API 36 مع حد أدنى API 24.
- تحسين fallback للتنبيهات الدقيقة عند عدم منح الإذن.
- إصلاح إيقاف الأذان والغفوة الصامتة وAudio Focus وتجديد مهام الخلفية، ومنع جدولة أذان الشروق.
- جعل أذونات الإعداد اختيارية وعدم حجب دخول التطبيق عند رفضها، وإيقاف الجدولة عند تعذر تحديد المنطقة الزمنية بدل افتراض موقع خاطئ.
- منع فقد زيادات التسبيح عند فشل الشبكة وإلغاء اشتراكات البث عند التخلص من الشاشات.
- إصلاح مقارنة الإصدارات الدلالية وسباق تراكب الراديو.
- قصر WebView سورة الكهف على نطاق Quran.com عبر HTTPS.
- احترام تكبير الخط الذي يحدده النظام.
- اعتماد edge-to-edge بدل الوضع الغامر، وإظهار تعذر مستشعر القبلة بدل التحميل غير المنتهي.
