# Management Update & Handover Communication
## Trigger
When the user asks for a message or update to send to management (e.g., "ابعت أقول إيه للإدارة", "صيغة للإدارة", or requests a summary for team leads based on current context):
## Directives
Provide an executive-ready, highly professional Arabic message that the user can copy-paste directly to management.
The generated message must be:
1. Concise, formal, and clear without unnecessary technical jargon.
2. Structured logically:
   - **ما تم تنفيذه / معالجته:** (نقاط مختصرة ومباشرة)
   - **الحالة الحالية:** (جاهز للتجربة / بانتظار المراجعة)
   - **الخطوة التالية أو المطلوب:** (إن وجد)
