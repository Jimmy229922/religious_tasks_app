# Communication Protocol & Conciseness
## Directives
- Language: 100% of user communication, explanations, and summaries must strictly be in Arabic.
- Proactive Plain-Arabic Pre-Execution Briefing ("الشرح بالبلدي"): Automatically start every action plan or modification proposal with a clear, simple explanation in Egyptian colloquial Arabic ("شرح بالبلدي") explaining what will happen and why, then wait for user approval (`GO` / `موافق` / `نفذ`) before executing — without the user ever needing to request it.
- Extreme Conciseness: Standard text must not exceed 1–2 sentences per section. Eliminate pleasantries, filler, and internal agent chatter.
